# Reusable Event Report Template

Scale the report to the actual request. A narrow query may need only a few events; a broad category survey may warrant an organizer directory, future opportunities, exclusions, and a day-by-day plan. Omit empty or irrelevant sections.

Use direct Markdown source links near claims. Keep the strongest currently actionable recommendations at the top.

## Field and wording rules

- Include the year when it is needed to distinguish stale listings.
- Name the venue's local time zone; label next-day endings explicitly.
- Use a full address only when a source verifies it. Mark a park address versus an exact organizer meeting point separately.
- Write “not publicly listed” rather than guessing an end time, cover, fee, instructor, address, or prerequisite.
- Separate mandatory costs from optional purchases, parking, taxes, service fees, suggested donations, or fundraising.
- Describe remaining capacity as a time-sensitive observation, not a guaranteed reservation.
- Explain whether beginner instruction is a brief social lesson, a standalone intensive, a multiweek course, or a full festival workshop program.
- Explain whether a meditation program is fully silent, mostly silent with explicit exceptions, guided, musical, ceremonial, or social.
- Identify age-specific or affinity-group eligibility prominently when it limits who can attend.
- Keep recurring, inferred, and secondary-only listings out of the verified-event section unless their status is unmistakably labeled.
- Treat an explicit first-party cancellation, closed deadline, or sold-out notice as stronger than cached availability.
- Cite each important claim close to its source; avoid dumping unsupported references at the end.

## Multiple subjects

When the user requests several unrelated categories, create a separate report for each unless they request a combined document. Reuse the same date range, geography, source standard, confidence conventions, and output directory. Provide a concise cross-category shortlist or compatible itinerary only when useful.

When a new specialized report overlaps an existing general report, link or reuse verified background where appropriate, but research its actual subtype independently. For example, a salsa-social listing is not automatically a salsa workshop, and a meditation venue is not automatically hosting a silent retreat.

## Final artifact checks

Verify that every requested report exists at its intended path, dates and weekdays are internally consistent, direct sources resolve as far as the available tools allow, and unsupported specifics are visibly marked unknown. Confirm the top recommendations are still upcoming and genuinely available relative to the target location's current time.
